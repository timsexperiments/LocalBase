# LocalBase

LocalBase runs AI models on your own computer and serves them through one OpenAI-compatible API, with a web interface on top.

- **New here?** [Install it](install.md), then follow the [quickstart](quickstart.md).
- **Connecting a tool?** See [connect an app](connect-an-app.md) and the [API overview](api.md).
- **Stuck?** Try [troubleshooting](troubleshooting.md).
- **Want to help?** See the [contributor guide](contributing.md).

The source is on [GitHub](https://github.com/timsexperiments/LocalBase). LocalBase is pre-1.0 and licensed under AGPL-3.0-or-later.

# Roadmap

This is the current direction, not a promise, and it has no dates.

**Next**

- Release 0.2.0, the Go version. See the [release checklist](docs/release-checklist.md).
- Remove the TypeScript version. See the [retirement plan](docs/typescript-retirement.md).

**Later**

- Qualify NVIDIA on Linux on real hardware: placement, memory admission and media runtimes.
- Qualify Linux x86-64 as an end-user install.
- Real device checks: phones, microphones and screen readers.
- Managed runtimes on more platforms.

**Not planned**

- Windows.
- Running several models of one type at once.
- Server-side chat history.

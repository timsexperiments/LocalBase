# Getting help

- **First:** [troubleshooting](docs/troubleshooting.md) and the [FAQ](docs/faq.md), then `local-base doctor`.
- **Bugs and feature ideas:** [open an issue](https://github.com/timsexperiments/LocalBase/issues/new/choose). Search existing ones first.
- **Security problems:** report privately. See [SECURITY.md](SECURITY.md).

This is a pre-1.0 project maintained on a volunteer basis, so there's no guaranteed response time. Only the latest release is supported.

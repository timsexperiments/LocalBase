### LGPL-2.1 §6 source offer and relinking information

The corresponding source and build material for the combined LocalBase executable, including Bun, its modified WebKit/JavaScriptCore, and LocalBase, can be obtained as follows. Bun is pinned to commit `0d9b296af33f2b851fcbf4df3e9ec89751734ba4` (tag `bun-v1.3.14`); WebKit is pinned to `5488984d20e0dbfe4be2c3ba8fb18eb81a5e0e8b`, the `WEBKIT_VERSION` in Bun's `scripts/build/deps/webkit.ts` at that commit.

```sh
git clone https://github.com/oven-sh/bun.git
cd bun
git checkout 0d9b296af33f2b851fcbf4df3e9ec89751734ba4
git clone https://github.com/oven-sh/WebKit.git vendor/WebKit
git -C vendor/WebKit checkout 5488984d20e0dbfe4be2c3ba8fb18eb81a5e0e8b
```

Install the prerequisites listed in the pinned Bun `CONTRIBUTING.md`: on macOS, automake, ccache, cmake, coreutils, gnu-sed, go, icu4c, libiconv, libtool, ninja, pkg-config, rust, and ruby; LLVM/Clang 21.1.8 is required. The build scripts install Zig automatically. A release Bun is also needed to run its build scripts. Follow the pinned contributing guide for platform-specific prerequisites.

```sh
bun run build:local
# Produces build/debug-local/bun-debug
```

To rebuild LocalBase's compiled executable with this custom Bun, from a LocalBase source checkout run:

```sh
/path/to/bun/build/debug-local/bun-debug build src/cli.ts --compile --no-compile-autoload-dotenv --no-compile-autoload-bunfig --outfile=local-base
```

These steps are documented-but-untested by LocalBase maintainers.

### LGPL-2.1 §6 source offer and relinking information

The corresponding source for the Bun runtime is available at the pinned Bun source archive: https://github.com/oven-sh/bun/archive/refs/tags/bun-v1.3.14.tar.gz. The corresponding modified WebKit/JavaScriptCore source is available at https://github.com/oven-sh/WebKit/archive/5488984d20e0dbfe4be2c3ba8fb18eb81a5e0e8b.tar.gz. The WebKit revision is pinned by `scripts/build/deps/webkit.ts` in the Bun tag. Copyright holder for this written offer: Tim Daltemus. For at least three years from distribution of this release, Tim Daltemus will provide the corresponding source on request through https://github.com/timsexperiments/LocalBase/issues.

To rebuild and relink, build Bun from source at `bun-v1.3.14` against the modified WebKit source, following the documented process in Bun's `LICENSE.md` at that tag (`git submodule update --init --recursive`, `make jsc`, then `zig build`). Then rebuild LocalBase from its AGPL source using that custom Bun binary with the repository's documented `bun run build` command, which invokes `bun build --compile`. These are the documented steps; LocalBase maintainers have not executed them as part of each release.

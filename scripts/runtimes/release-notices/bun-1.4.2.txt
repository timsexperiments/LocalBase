### LGPL-2.1 §6 source offer and relinking information

The corresponding source and build material for the combined LocalBase executable, including Bun, its modified WebKit/JavaScriptCore, and LocalBase, can be obtained as follows. Bun is pinned to commit `744846f844374847c902b5e7fd59b4342a51ef99` (tag `bun-v1.4.2`); WebKit is pinned to `2e2aa2290fac856d6f451ceacb58f7f5b44dd057`, the `WEBKIT_VERSION` in Bun's `scripts/build/deps/webkit.ts` at that commit.

```sh
git clone https://github.com/oven-sh/bun.git
cd bun
git checkout 744846f844374847c902b5e7fd59b4342a51ef99
git clone https://github.com/oven-sh/WebKit.git vendor/WebKit
git -C vendor/WebKit checkout 2e2aa2290fac856d6f451ceacb58f7f5b44dd057
```

`bun sync-webkit-source` in the Bun checkout performs the same WebKit checkout from the pinned `WEBKIT_VERSION`.

Install the prerequisites listed in the pinned Bun `CONTRIBUTING.md`: on macOS, automake, ccache, cmake, coreutils, gnu-sed, go, icu4c, libiconv, libtool, ninja, pkg-config, rustup-init, and ruby; LLVM/Clang 21.1.8 is required. Bun's runtime includes Rust code built with the nightly toolchain pinned in its `rust-toolchain.toml` (`nightly-2026-07-20`), which rustup installs automatically. The build scripts install Zig automatically. A release Bun is also needed to run its build scripts. Follow the pinned contributing guide for platform-specific prerequisites.

```sh
bun run build:local
# Produces build/debug-local/bun-debug
```

To rebuild LocalBase's compiled executable with this custom Bun, from a LocalBase source checkout run:

```sh
bun install --frozen-lockfile
/path/to/bun/build/debug-local/bun-debug build src/cli.ts --compile --no-compile-autoload-dotenv --no-compile-autoload-bunfig --outfile=local-base
```

The install step also generates the UI bundle and migration assets required by the compile. These relink steps are documented but have not been tested end to end with a custom JavaScriptCore build.
